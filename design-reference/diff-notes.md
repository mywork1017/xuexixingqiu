# PRD 目标 HTML 与当前实现差异

## 基准文件

- 地图目标 HTML：`design-reference/map.html`
- 详情目标 HTML：`design-reference/detail.html`
- 我的目标 HTML：`design-reference/mine.html`
- 并排对比：`design-reference/compare.html`

## 整体视觉差异

- PRD 目标是深色沉浸式界面：墨绿黑底、金色强调、宋体/衬线标题、大量半透明层和暖色高光。
- 当前实现是浅色卡片界面：米色卡片、深绿背景、默认腾讯地图瓦片，整体更接近传统小程序信息卡。
- PRD 目标的按钮、标签、分割线、图标都带金色体系；当前实现主要是深绿主按钮和米色描边按钮。
- PRD 目标依赖视觉资产：暗色地图背景、图书馆/书店氛围图、圆形图标标记；当前实现缺少这些资产层。

## 地图页差异

- PRD 目标顶部为居中标题和一排紧凑分类胶囊；当前实现标题靠左，筛选区域像双列大 pill。
- PRD 目标地图是暗色定制地图，地点以图标 pin 和文字呼出展示；当前实现是默认亮色腾讯地图加彩色圆点。
- PRD 目标选中地点为“思南书局”，底部卡片有大圆形图标、地址、时间、标签、距离、分割线和三枚图标按钮。
- 当前底部卡片是浅米色信息面板，层级、图标密度、按钮材质和 PRD 目标差距明显。
- 地图底图的暗色样式和地图内标记能力需要后续单独迭代；本轮先把页面 UI 层往目标靠齐。

## 详情页差异

- PRD 目标有顶部封面大图，当前实现以米色信息卡作为开头。
- PRD 目标内容区域是深色背景上的金色分区标题和细分割线；当前实现是多个米色卡片堆叠。
- PRD 目标主信息区为大圆形分类图标 + 大标题 + 地址，操作按钮是金色描边暗绿底；当前实现按钮更像普通表单按钮。
- PRD 目标周边列表是深色列表行，当前实现仍使用卡片式浅色容器。

## 我的页差异

- PRD 目标顶部是图书馆氛围背景，头像、登录态和设置入口直接浮在图上；当前实现是米色账号卡。
- PRD 目标收藏区为深色列表，展示 3 个收藏地点；当前实现的背景分区和卡片结构仍偏浅色。
- PRD 目标 tabbar 是黑金风格，激活态有金色图标和底部短线；当前 tabbar 是深绿底加蓝色图标。

## 后续开发判断

- 小程序原生组件可以完成大多数 UI 层还原：背景、卡片、按钮、列表、封面、tabbar、图标和排版都能继续靠近目标。
- 地图本体会有技术限制：微信 `map` 组件的瓦片、POI、道路细节很难做到目标图那种完全自定义暗色插画质感。要接近目标，需要尝试地图自定义样式、覆盖层标记、或后续改成静态/半静态地图视觉层加真实导航能力。
- 本轮修改先落实 UI 容器、颜色、排版、按钮、列表和视觉资产；地图底层在下一轮单独评估。
