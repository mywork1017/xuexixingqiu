# 上海学习地图地图迭代 PRD

## 背景

当前小程序已经支持地图展示、分类筛选、列表和详情页。下一轮迭代重点是降低地图首屏干扰、提升地点信息密度、加入收藏路径，并为后续照片与周边探索打好数据结构基础。

## 目标

1. 地图首屏保持干净，默认不弹出地点浮层。
2. 用户点击点位后，在地图页直接看到更完整的地点摘要，并可导航、收藏、进入详情。
3. 地图点位统一为单一圆点 icon，不叠加文字 label。
4. 顶部类型筛选更轻量，支持多选，并用与地图点位一致的颜色圆点提示类型。
5. 地图低缩放级别减少点位密度，高缩放级别展示当前范围内所有地点。
6. 地图加载优先围绕可见范围，支持后续扩展为屏幕九宫格缓存。
7. 地点地址字段展示更完整，地点支持收藏。
8. 详情页支持照片、单地点地图、2 公里周边点位开关和周边类型多选。
9. 底部菜单增加“地图”和“收藏”，收藏页展示收藏地点列表，点击后进入同一详情页。

## 用户故事

1. 作为用户，我打开地图时希望先看空间分布，点击感兴趣的点位后再看地点信息。
2. 作为用户，我想按多种地点类型同时筛选，例如同时看图书馆和自习室。
3. 作为用户，我想在地图上快速识别不同类型地点，并避免文字遮挡地图。
4. 作为用户，我想收藏地点，之后从收藏菜单快速找回。
5. 作为用户，我想在详情页看照片、导航、专属地图和附近 2 公里内的其他可学习地点。

## 范围

### 本次实现

- 地图页默认 `selectedPlace = null`。
- 点击 marker 后展示底部浮层。
- 浮层展示类别、名称、详细地址、开放时间、标签、简介摘要、导航、收藏、详情入口。
- 顶部类型 tab 改为紧凑多选，默认全选；每个 tab 显示类型色圆点。
- marker 改为本地圆点图标，每种类型一种颜色。
- 地图缩放策略：
  - 缩放级别低于 11 时只展示大型/优先级地点。
  - 缩放级别 11 及以上时展示可见范围内所有匹配类型地点。
- 地图加载策略：
  - 本次优先用本地缓存/云函数返回的地点，在客户端按可见范围过滤。
  - 保留屏幕九宫格缓存的工具函数和状态位，为数据量增长后的云端分页做准备。
- 收藏：
  - 使用本地存储保存收藏地点 id。
  - 地图浮层和详情页都可收藏/取消收藏。
  - 新增收藏页，展示收藏列表。
- 详情页：
  - 支持 `photos` 或 `imageUrls` 字段展示照片。
  - 展示只包含当前地点的专属地图。
  - 支持打开/收起周边 2 公里地点。
  - 周边点位支持多类型筛选。
- 底部 tabBar：
  - 地图。
  - 收藏。

### 本次不实现

- 直接抓取百度、高德、小红书、大众点评图片并入库。
- 云端按九宫格分页接口。
- 用户账号体系下的云端收藏同步。
- 照片上传审核后台。

## 第三方照片来源判断

百度地图开放平台和高德开放平台服务条款都限制通过技术手段抓取或直接存储相关服务数据和图片。小红书用户协议、美团点评平台协议也限制非法抓取平台图文、内容数据。基于合规和稳定性，本次采用自有字段 `photos` / `imageUrls` 展示照片。照片来源建议走人工补录、版权可用图片、地点官方授权素材，或后续接入明确允许展示的正式 API。

## 数据设计

地点对象在现有字段基础上扩展：

```json
{
  "priority": "major",
  "photos": ["https://example.com/photo.jpg"]
}
```

- `priority`：可选，`major` 表示低缩放下也展示；缺省时图书馆默认视为较高优先级。
- `photos` / `imageUrls`：可选，字符串数组，详情页展示。

收藏存储：

```json
{
  "favoritePlaceIds": ["place_abc"]
}
```

## 交互设计

### 地图页

- 打开页面：默认上海中心点，顶部多选类型，全量类型默认选中，无浮层。
- 点击 marker：底部浮层出现，展示地点摘要。
- 点击空白区域或切换筛选：浮层关闭。
- 点击导航：调用 `wx.openLocation`。
- 点击收藏：本地收藏状态切换。
- 点击详情：进入详情页。
- 缩放/拖动地图：根据当前缩放和可见范围刷新 marker。

### 收藏页

- 底部 tab 进入。
- 展示已收藏地点列表。
- 空状态只提示暂无收藏。
- 点击地点进入详情页。

### 详情页

- 顶部展示照片横向区域；无照片时不显示照片模块。
- 展示基础信息和操作按钮。
- 专属地图只展示当前地点 marker。
- 周边模块默认收起，用户点击后展示 2 公里内其他地点。
- 周边筛选为多选类型，默认全选。

## 验收标准

1. 地图页首次打开不展示地点浮层。
2. 任一 marker 被点击后展示浮层，浮层包含导航和收藏按钮。
3. 地图 marker 只有圆点 icon，没有文字 label。
4. 顶部类型 tab 可多选，颜色与 marker 对应。
5. 缩放到低级别时 marker 数量减少；缩放到 11 及以上时展示当前可见范围内所有匹配点。
6. 地图移动后 marker 根据可见范围刷新。
7. 地点可收藏，收藏页可看到收藏列表并进入详情。
8. 详情页能展示照片字段、单地点地图和 2 公里周边列表。
9. `npm test` 通过。
10. JS 语法检查通过。

## 风险与后续

- 微信小程序 map marker 和 tabBar 使用项目内 PNG 图标，减少本地图标格式兼容风险。
- 当前数据量较小，客户端可见范围过滤足够；数据增长后再把九宫格缓存和范围查询下沉到云函数。
- 第三方照片需要合规来源，后续可增加图片来源字段、版权标注和审核流程。
