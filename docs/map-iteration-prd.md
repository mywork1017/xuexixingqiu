# 上海学习地图海派视觉迭代 PRD

## 背景

当前小程序已具备地图点位、地点详情、收藏列表、导航等基础能力。本次迭代聚焦视觉系统和页面结构重塑：将产品从默认小程序样式升级为更有上海文化气质的深色地图体验，同时保持现有功能边界清晰、可落地。

## 目标

1. 建立统一的“海派夜读”视觉风格：深墨地图、象牙内容面、暗绿控件、铜金强调色。
2. 地图页保留地图主体验，加入真实微信小程序标题栏和右上胶囊按钮避让。
3. 一级 tab 只保留两个入口：`地图`、`我的`。
4. `我的` 页承载微信登录状态和收藏地点列表。
5. 详情页作为二级页面展示，无底部 tabbar。
6. 保持现有核心功能：分类筛选、地图 marker、地点卡片、导航、收藏、详情、周边 2 公里。

## 页面范围

### 地图页

- 页面类型：一级 tab 页面。
- 顶部结构：
  - 显示状态栏安全区。
  - 自定义标题栏展示 `上海学习地图`。
  - 右上角预留微信小程序胶囊按钮区域。
- 地图主体：
  - 使用深色地图视觉。
  - 如已开通腾讯位置服务个性化地图，使用 `subkey` 和 `layer-style` 接入深色底图。
  - 未开通时，先使用深色 UI 控件、深色浮层、自定义 marker 保持整体风格。
- 筛选：
  - 筛选项第一项为 `全部`。
  - 后续分类为 `图书馆`、`书店`、`自习室`、`党群服务中心`、`社区食堂`。
  - 筛选条位于标题栏下方，不遮挡胶囊按钮。
- marker：
  - 使用类别色和类别图标区分地点。
  - 保留当前点击 marker 展示地点卡片的交互。
- 底部地点卡片：
  - 固定在地图底部 tabbar 上方。
  - 卡片不可上滑展开。
  - 展示地点名称、地址、开放时间、营业状态、标签、距离。
  - 地点名称后不显示类别标签。
  - 操作按钮：`导航`、`详情`、`收藏`。
- 底部 tabbar：
  - `地图`、`我的` 两个 tab。
  - 地图页激活 `地图`。

### 我的页

- 页面类型：一级 tab 页面。
- 顶部结构：
  - 显示状态栏安全区。
  - 自定义标题栏展示 `我的`。
  - 右上角预留微信小程序胶囊按钮区域。
- 账号区：
  - 展示微信头像、昵称、登录状态。
  - 保留退出入口。
  - 移除 `管理账号` 模块。
- 收藏区：
  - 标题为 `我的收藏`。
  - 展示收藏地点数量。
  - 收藏列表展示地点图标、名称、类别、地址、开放时间和进入详情箭头。
  - 点击收藏地点进入详情页。
- 底部 tabbar：
  - `地图`、`我的` 两个 tab。
  - 我的页激活 `我的`。

### 详情页

- 页面类型：二级页面。
- 顶部结构：
  - 显示状态栏安全区。
  - 左侧返回按钮。
  - 标题为 `地点详情`。
  - 右上角预留微信小程序胶囊按钮区域。
- 底部结构：
  - 不显示 tabbar。
- 内容结构：
  - 顶部可展示地点照片；无照片时隐藏照片区域。
  - 展示地点图标、地点名称、地址。
  - 地点名称后不显示类别标签。
  - 操作按钮只保留 `导航`、`收藏`。
  - 移除电话入口。
  - 展示 `位置` 小地图。
  - 展示 `开放时间`。
  - 展示 `简介`。
  - 展示 `标签`。
  - 展示 `周边 2 公里` 模块。
- 周边模块：
  - 筛选项第一项为 `全部`。
  - 后续分类为 `图书馆`、`书店`、`自习室`、`社区食堂`。
  - 周边列表展示地点名称、类别、地址、距离和进入详情箭头。

## 视觉规范

### 色彩

- 页面底色：深墨黑、暗青黑。
- 内容面：象牙白、暖纸白。
- 主控件：暗绿。
- 强调色：铜金。
- 类别色：
  - 图书馆：橄榄绿。
  - 书店：铜金。
  - 自习室：蓝紫。
  - 党群服务中心：朱红。
  - 社区食堂：黄绿。

### 字体与层级

- 保持微信小程序中文阅读友好。
- 主要标题使用较大字号和较高字重。
- 地点元信息使用中等字号，降低对比度。
- 辅助信息使用图标加文字，减少长段说明。
- 正文、列表、按钮默认使用系统字体：`PingFang SC`、`-apple-system`、`Helvetica Neue`、`Arial`。
- 特殊字体仅作为标题增强项，用于 `上海学习地图`、`地点详情`、地点名称等少量标题文本。
- 特殊字体通过 `wx.loadFontFace` 从云存储或 CDN 加载，加载失败时回退系统字体。
- 字体文件需要控制体积，优先使用中文子集；首屏核心信息不得依赖特殊字体才能阅读。

### 装饰约束

- 不使用印章装饰。
- 不展示口号。
- 不展示天气。
- 不提供搜索框。
- 不做纯列表地图页。
- 页面内不写产品策略、设计策略或数据规则说明。

## 功能规则

### 分类筛选

- 地图页和详情页周边模块的筛选第一项均为 `全部`。
- `全部` 激活时展示全部类别。
- 用户选择单个类别时，仅展示该类别地点。
- 后续如需要多选，可在此基础上扩展。

### 收藏

- 地图卡片、详情页均可收藏或取消收藏。
- 收藏状态同步影响 `我的` 页收藏列表。
- `我的` 页为空时展示简洁空状态。

### 导航

- `导航` 继续调用 `wx.openLocation`。
- 导航按钮在地图卡片和详情页均保留。

### 详情跳转

- 地图卡片点击 `详情` 进入二级详情页。
- `我的` 页点击收藏地点进入同一详情页。
- 详情页返回按钮回到来源页面。

## 数据需求

### 账号数据

不同微信账号的数据使用云数据库存储，并通过 `_openid` 做用户隔离。

用户资料集合建议：

```json
{
  "_id": "profile_auto_id",
  "_openid": "openid_from_cloud_context",
  "nickName": "微信用户",
  "avatarUrl": "cloud://.../avatars/user-avatar.jpg",
  "createdAt": "2026-06-20T00:00:00.000Z",
  "updatedAt": "2026-06-20T00:00:00.000Z"
}
```

用户收藏集合建议：

```json
{
  "_id": "favorite_auto_id",
  "_openid": "openid_from_cloud_context",
  "placeId": "sample-bookstore",
  "createdAt": "2026-06-20T00:00:00.000Z"
}
```

规则：

- 前端不传用户 ID。
- 云函数使用 `cloud.getWXContext().OPENID` 获取当前用户。
- 查询、创建、删除收藏时均按 `_openid` 限定范围。
- 同一用户同一地点只保留一条收藏记录。
- 退出入口清理本地登录态和页面展示状态；云端收藏数据保留。

### 文件资源

图片、字体等文件资源放云存储；结构化账号数据放云数据库。

资源建议：

- 地点照片：`cloud://.../places/{placeId}/cover.jpg`
- 类别默认图：`cloud://.../place-category/{category}.jpg`
- 用户头像缓存：`cloud://.../avatars/{openid}.jpg`
- 字体文件：`cloud://.../fonts/brand-title-subset.woff2`

策略：

- 当前阶段优先使用微信云存储，减少权限和域名配置成本。
- 后续图片量、访问量或 CDN 成本明显增加时，再评估迁移到对象存储服务。
- 地图页和我的页不依赖大图；详情页照片作为增强内容。
- 字体、图片加载失败时，页面使用默认图或系统字体兜底。

### 地点数据

沿用现有地点字段：

```json
{
  "id": "sample-bookstore",
  "name": "思南书局",
  "category": "书店",
  "latitude": 31.2139,
  "longitude": 121.4662,
  "address": "上海市黄浦区复兴中路517号",
  "hours": "10:00-21:00",
  "tags": ["书店", "阅读"],
  "description": "人文气质浓厚的书店空间，适合阅读和选书。"
}
```

建议扩展字段：

```json
{
  "coverImage": "cloud://.../places/sinan-bookstore-cover.jpg",
  "photos": ["cloud://.../places/sinan-bookstore-1.jpg"],
  "openStatusText": "营业中",
  "distanceText": "1.8 公里"
}
```

图片缺失时：

- 地图页不依赖大图。
- 我的页不依赖大图。
- 详情页隐藏照片区域或使用类别默认图。

## 验收标准

1. 地图页顶部显示 `上海学习地图` 标题，并避让右上胶囊按钮。
2. 地图页筛选第一项为 `全部`。
3. 地图页底部地点卡片的地点名称后无类别标签。
4. 我的页无 `管理账号` 模块。
5. 我的页保留账号信息、退出入口和收藏列表。
6. 详情页为二级页面，显示返回按钮，无底部 tabbar。
7. 详情页地点名称后无类别标签。
8. 详情页无电话入口。
9. 地图页、我的页、详情页视觉风格统一。
10. 页面不展示口号、天气、搜索框、印章装饰。
11. 不同微信账号的收藏数据按 `_openid` 隔离。
12. 退出后本地登录态清空，云端收藏数据不被删除。
13. 特殊字体加载失败时，标题和内容回退系统字体且可正常阅读。
14. 图片加载失败时，页面使用类别默认图或隐藏照片区域。
15. `npm test` 通过。
16. JS 语法检查通过。

## 后续实现备注

- 自定义顶部导航栏应读取系统状态栏高度和胶囊位置信息，避免写死顶部间距。
- 深色地图优先接入微信小程序 `map` 的 `subkey` 与 `layer-style`；未开通个性化地图时，以 UI 层先完成可验证版本。
- 详情页作为 `navigateTo` 页面保留返回栈，页面配置和 tabbar 页面区分处理。
- 图片来源需满足版权和授权要求，早期版本优先使用类别默认图或人工补录图片。
- 账号相关云函数应统一从云端上下文读取 `_openid`，避免前端伪造用户身份。
- 特殊字体加载应放在应用启动或页面进入时提前触发，并提供系统字体兜底。
